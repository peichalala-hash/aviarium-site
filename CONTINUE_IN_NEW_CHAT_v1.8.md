## Проект: сайт AVIARIUM

**Путь к сайту:** `04_Business_New/AVIARIUM_site/`  
**Текущая версия:** 1.8  
**Бэкап v1.8:** папка `04_Business_New/AVIARIUM_site_v1.8` (полная копия сайта на момент версии 1.8)

**Суть проекта:** Презентационный сайт премиального бренда AVIARIUM — подарочные наборы редких куриных яиц в авторской упаковке (ларцы, кейсы, шкатулки). Аудитория — РФ, премиум-сегмент.

## Что уже сделано (кратко)

- **Главная (index.html):** Hero, блок «Листайте вниз» (ссылка на #about), О нас, Наш авиариум (6 пород — картинка и название ведут на страницы пород), Коллекции (12 карточек, ссылки на страницы коллекций), Скорлупа, «Когда яйца съедены», допокупка яиц, калькулятор, писанки и умные шкатулки, Калькулятор набора яиц, корзина, модальное оформление заказа, Сервис, Контакты. Кнопки «Вниз» (у верха) и «Наверх» (при прокрутке) справа внизу; чат-помощник слева внизу (выше панели задач: bottom: 5rem).
- **Страницы коллекций (12 шт.):** collection-*.html. Блок «Яйца в наборе» с изображением ларца справа; кнопка «Заказать» открывает модальное окно быстрого заказа (имя, телефон, продукт и цена уходят в POST /api/callback). Ссылка «← Коллекции» на главную. Кнопка «Наверх» на каждой.
- **Страницы пород (7 шт.):** breed-araukana.html, breed-uheilyuy.html, breed-maran.html, breed-olivegger.html, breed-legorn.html, breed-orpington.html, breed-maran-dark.html. Разделы: О породе (с фото), Яйценоскость, Условия содержания, Характеристики яйца, В наших наборах. Ссылка «← Наш авиариум», кнопка «Наверх».
- **Корзина и заказ:** добавление в корзину из калькулятора и с карточек упаковок, спираль яиц, модалка оформления заказа (имя, телефон, email, адрес, срочность, дата, комментарий), экран «Заявка отправлена». Быстрый заказ с коллекций — отдельная модалка (getQuickOrderModal, openQuickOrder в script.js).
- **Бэкенд (backend/):** Node.js, server.js — API для чата и для callback (в т.ч. product, price для быстрого заказа). См. README и .env.example.
- **Версия:** в файле VERSION и в подвале всех страниц — «Сайт v1.8».
