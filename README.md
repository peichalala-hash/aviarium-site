# AVIARIUM — премиум-сайт (прототип)

Одностраничный визуальный прототип по концепции из заметки `AVIARIUM_премиум_яйца_концепция_сайта.md`.

## Переключение мобильная / полная версия

В правом нижнем углу — кнопка **«Мобильная версия»**. По нажатию открывается оверлей с превью сайта в ширине смартфона (390px). Кнопка **«Полная версия»** закрывает оверлей.

## Как посмотреть

1. Откройте файл **`index.html`** в браузере (двойной клик или «Открыть с помощью» → браузер).
2. Или запустите локальный сервер в этой папке, например:
   - `npx serve .`
   - или Python: `python -m http.server 8080` и откройте http://localhost:8080

Шрифты подгружаются с Google Fonts — нужен интернет для полного отображения.

## Содержимое

- **Hero** — первый экран с заголовком и CTA
- **О нас** — философия бренда
- **Каталог** — три коллекции (Рассвет Империи, Лазурит, Перламутр и Золото)
- **Скорлупа как холст** — блок о качестве
- **Гастрономия и сервис** — выездной завтрак, персонализация
- **Подвал** — контакты, форма обратного звонка, юридический текст

Дизайн: антрацит, приглушённое золото, Playfair Display + Source Sans 3, адаптивная вёрстка.

## Чат-помощник

Сайт подключён к бэкенду с API нейросети. Виджет чата — кнопка слева внизу; ответы ведёт помощник AVIARIUM.

- **Бэкенд:** папка `backend/`. Запуск: `cd backend && npm install && npm start`. В `.env` задайте `OPENAI_API_KEY` (или совместимый API).
- **URL бэкенда** задаётся в `index.html`: `window.AVIARIUM_CHAT_API = 'http://localhost:3000'`. На продакшене укажите ваш домен.
- Подробнее: `backend/README.md`.
